## Ejecutar Cocina Clara
```bash
cd CocinaClara
PORT=3107 npm start
```
Abrir `http://localhost:3107`. Las recetas externas dependen de la API de recetas y la IA generativa requiere una clave privada configurada en el servidor.

No guardar secretos, historiales privados ni bases de datos personales en GitHub.
